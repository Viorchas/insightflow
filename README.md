# InsightFlow

AI 用户反馈洞察与需求管理交互演示，内置虚构 chatagent 产品的 204 条合成反馈。

在线体验（启用 Pages 后）：https://viorchas.github.io/insightflow/

本仓库根目录 index.html 为可直接托管的静态构建，界面资源已内嵌，无外部依赖。完整源码、开发文档和测试见 [InsightFlow-source.zip](./InsightFlow-source.zip)。

页面支持独立的云端真实 AI 接口，需由作者配置并启用。关键词模拟不调用 AI；真实分析由访客明确确认，并受服务端限额约束。反馈保存在访客浏览器，密钥不包含在仓库或源码包中。

演示数据不代表真实用户研究、客户案例或业务成绩。
